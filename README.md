# ACE COMBAT 8 互动音乐播放器

在 Windows 上按游戏的段落、循环点和分轨播放《皇牌空战 8》配乐。播放器记录每首曲子上次选择的编排，支持按遍数和小节切换分轨，也可以在自由编排中手动排队或立即切段。

## Android 手机播放

手机版使用 Kotlin、Jetpack Compose 和 Material 3 Expressive。Android 8.0 及以上的 arm64 手机可以接收音乐，x86_64 模拟器也可以运行。首次使用时将手机和电脑连到同一局域网。

1. 在电脑右上角点击手机图标，选择「展示连接二维码」。在手机版的「传输」里扫码，也可以输入电脑复制的配对码。
2. 手机会优先尝试同一 Wi-Fi 网段的电脑地址，并回传本机曲库。在电脑选择「曲库」可以按曲选编排，选择「播放列表」可以勾选已加入列表的单曲和编排，也可以全选。发送时只取当前来源中勾选的内容，同一首歌的音频只传一份，默认编排随曲传输。「同时传输座舱音效包」可以单独勾选。
3. 传完后在手机「曲库」中点歌。可以直接听传入的编排，或选「自由编排」实时排队切段、立即切段、调整循环、开关分轨。音乐支持离线和锁屏播放。手机使用 48 kHz 立体声输出，电脑发送可按采样点定位的 PCM 音轨。再次发送已有曲目时，手机复用已有音频，只接收缺少的文件和选中的编排。

手机曲库按编排列出曲目，并标明是否无限循环。打开「正在播放」可以查看完整编排和当前步骤。手机支持顺序播放、随机播放、列表循环和单曲循环。电脑从「播放列表」发送的勾选项按原顺序出现在手机的「电脑播放列表」，重复条目也会保留。再次从播放列表发送会更新这份列表，已传的曲目和编排仍可在「全部曲目」找到。

手机播放页的沙盘跟随实际输出的音乐和座舱音效。顶部中间控制播放，左上角齿轮展开编排、分轨和座舱音效设置，右上角列表展开队列与播放模式。点面板外或用系统返回手势即可收起。

## 电脑之间迁移配置

右上角手机图标里有「导出配置 JSON」和「导入配置 JSON」。文件包含全部自定义编排、播放列表条目、顺序和播放模式。同一曲目下的同 ID 编排以及同 ID 列表条目会被更新，本机独有的内容会保留。默认编排继续使用播放器自带的版本。

## 使用

完整解压 ZIP，运行 `皇牌空战8音乐播放器.exe`，确认自动找到的 Steam 安装目录或手动选择。默认直接读取游戏，只临时解码当前曲目和启用的音效。右上角的“设置”可以更改目录，也可以提取音频供离线播放。基础配乐和座舱音效约占 5.9 GiB，其中线上模式配乐约占 3.0 GiB。另选全部原生 7.1.4 素材约增加 3.9 GiB。播放器优先使用程序旁 `audio` 中已提取的文件，缺少时再从游戏读取。提取的素材可以随播放器整个目录搬走。

当前索引对应 Steam App 2288340、构建 26002268。曲库含 76 首互动配乐和 342 个单曲条目。在「单曲」中搜索「线上」可以看到 154 个线上任务、机库和菜单条目，以及 77 个大厅点唱机条目。部分曲子有两个版本，例如《Daredevil》的紧急出击版会在游戏的循环点折返，大厅点唱机版会播放到结尾。曲名待核的条目按使用场景显示，也可以加入播放列表。

点击播放模式按钮或按 `T`，可以切换顺序播放、随机播放和单曲循环。选择单曲循环后，互动配乐会在当前编排放完时从头重播。

在曲库中选中单曲或互动配乐的编排，点击「加入播放列表」。切换到「播放列表」可以调整顺序或移除条目，列表会保存在本机。双击条目或点击「播放列表」会从选中项开始播放。顺序播放到末尾停止，列表循环会回到第一项，也可以选随机播放或单曲循环。带 ∞ 的条目按曲子或编排本身持续循环，想继续时点「下一首」。

播放器自动匹配 Windows 默认设备支持的输出布局。右下角的 `5.1（混音）` 表示当前曲目的分轨扩展为 5.1，`5.1（原生）` 表示原生多声道素材折叠至设备的 5.1。7.1.4 输出会保留这类素材的十二个独立声道，包括原有的 LFE。

本版游戏的 BGM 素材采样率均为 48 kHz。播放器保留原采样率，以 32 位浮点解码和混音，并在同一声道布局下优先使用浮点输出。右下角分别显示音源采样率和实际提交给 Windows 的流格式。

在 Windows 上，右上角的显示器按钮可把频谱沙盘放到桌面图标后面。开启后，沙盘只在桌面绘制，旁边的运镜按钮也控制桌面视角。再点一次即可恢复原桌面。点击窗口的 × 可以选择退出或隐藏到系统托盘。左键点击托盘图标可恢复窗口，右键菜单可播放、暂停、停止或退出。暂停保留进度，停止回到当前曲子或编排的开头。

## 从源码构建 Windows x64 发行包

使用 Windows x64、Rust MSVC 工具链、Visual Studio C++ Build Tools（含 Windows SDK）和 Python 3.11 或更高版本。运行桌面界面需要 Microsoft Edge WebView2 Runtime。

```powershell
python scripts/build.py
```

脚本使用 `desktop/Cargo.lock` 构建 Tauri 程序，下载并校验固定版本的便携 Python、NumPy 和解码器，再将发行 ZIP 写入 `dist/`。构建机无需安装游戏。已有完整依赖缓存时，可运行 `python scripts/build.py --offline`。接收者使用随包提供的 Python 运行环境。

## 项目目录

- `desktop/` 是 Tauri 外壳和 HTML、CSS、JavaScript 界面，包括频谱沙盘。
- `android/` 是原生安卓客户端。使用 JDK 17 或更高版本、Android SDK 37.1、Build Tools 36.0.0 和 Python 3.13，在该目录运行 `gradlew.bat assembleDebug`。可通过环境变量 `AC8_BUILD_PYTHON` 指定 Python 路径。APK 位于 `app/build/outputs/apk/debug/`。Gradle 从 `app/` 复制两端共用的编排、音轨和座舱混音引擎。
- `app/` 实现播放、编排、本机游戏导入和座舱音效。桌面入口使用 `bridge.py`。
- `library/` 保存曲库、默认编排和导入索引。游戏音频由接收者从自己的安装目录提取。
- `scripts/` 包含发行构建脚本。维护曲库时可使用 `scripts/metadata/` 中的工具和本机准备的音库元数据。
- `notices/` 保存随发行包提供的第三方组件说明。

### Android 签名与发布

推送版本标签（如 `v1.2.3`）会同时构建 Windows ZIP 和 Android APK，通过校验后一起附到 GitHub Release。APK 显示版本为 `1.2.3`，内部版本号随标签递增。也支持 `v1.2.3-beta.1` 这样的预发布标签。手动运行工作流时留空标签，可以只验证构建。

在 `android/` 运行 `gradlew.bat :app:assembleRelease` 可得到 `app/build/outputs/apk/release/app-release.apk`。本地优先使用当前提交上的版本标签，无标签时使用 `desktop/Cargo.toml` 的版本。

维护者换电脑时，克隆仓库，安装 [age](https://github.com/FiloSottile/age)，在 `android/local.properties` 添加 `ac8.signing.identity=C:/Users/你的用户名/.ssh/id_rsa`。如果 age 未加入 PATH，可用 `ac8.signing.age` 指定程序路径。Gradle 会用这把 SSH 私钥解开项目签名口令，本地 debug 和 release 均使用同一张证书。其他开发者可直接构建普通调试包。

项目的加密密钥库、SSH 加密的恢复口令和公开证书指纹位于 `android/signing/`。GitHub Actions 从仓库 Secret `AC8_ANDROID_SIGNING_PASSWORD` 取得口令，签完 APK 会核对指纹。
